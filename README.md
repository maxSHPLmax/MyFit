# MyFit 🏃

Простой фитнес-трекер для подсчёта калорий и физической активности.

## Что умеет

- Добавлять продукты с автоподсчётом калорий по весу
- Записывать физическую активность (бег, ходьба, велосипед и т.д.)
- Показывать дневной баланс калорий (съедено − сожжено)
- Отслеживать прогресс к дневной цели

## Технологии

- HTML / CSS / JavaScript (без фреймворков)
- База продуктов в `products.js`

## Как запустить

1. Открой `index.html` в браузере — и всё работает.

## Структура

```
MyFit/
├── index.html      — разметка
├── style.css       — стили
├── app.js          — логика
├── products.js     — база продуктов
└── README.md       — этот файл
```
